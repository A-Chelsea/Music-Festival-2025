<h1>Music Festival 2025</h1>
A music festival website developed during my first year at university using HTML, CSS and JavaScript.

<h2>Features</h2> 
<ol>
<li>Festival Homepage: Allows users to navigate between the different pages of the website.</li>
<li>Artist Line-up: Displays the artists performing at the festival.</li>
<li>Festival Schedule: Shows the schedule of performances across the three-day festival.</li>
<li>Ticket Page: Displays the available ticket options and prices.</li>
<li>JavaScript Functionality: Adds interactive features to improve the user experience.</li>
<li>Responsive Styling: Uses CSS to create an easy-to-navigate and visually appealing website.
</ol>
